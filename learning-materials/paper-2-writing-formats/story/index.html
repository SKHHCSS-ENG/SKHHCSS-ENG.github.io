P2 · Part B

Story

Narrate one clear event. Usually past tense; use any given first or last line exactly.

P2 / P3B: P2 mainly (Part B). A first or last line is often given — use it exactly, in the place asked. Invent a clear plot; usually past tense.

PAT
PurposeTell one clear event so the reader can follow what happened and why it mattered.
AudienceA general reader. Write as a complete story, not a letter or a diary unless the task says so.
ToneNarrative and vivid, but still controlled. Usually past tense; keep the same tense throughout.
Structure

Opening

  • A short title if asked
  • If a given first line is provided, use it exactly as your first sentence
  • Set the setting and introduce one or two characters quickly

Body

  • One main event or problem — do not start a second story
  • Build the problem, then a short climax
  • Show what people did and felt; a little dialogue is useful if it is short and natural

Closing

  • Give a clear resolution (what changed, or what the narrator learnt)
  • If a given last line is provided, use it exactly as your final sentence — plan backwards so it feels natural
  • No letter sign-off, and no “The End”
Skeleton

Slots: [given line / turning point] · [character / event] · [detail / feeling] · [other]

Opening

[Title]
[Given first line, if any — use it exactly]
That morning, [character] was [setting / situation].

Body

At first, everything seemed [normal detail]. Then [the problem].
[Character] tried to [action], but [it got worse].
All of a sudden, [climax]. “[short dialogue],” [someone] said.

Closing

In the end, [resolution].
[Given last line, if any — use it exactly as the final sentence]
Useful Phrases
  • It all started when…
  • At first, I thought…
  • All of a sudden,…
  • Little did I know that…
  • Without thinking twice, I…
  • “What should we do now?” I whispered.
  • In the end,…
  • From that day on,…
