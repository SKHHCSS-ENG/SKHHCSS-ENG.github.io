P2 / P3B

Formal letter / email

Write to one reader or organisation. Formal, polite, clear.

P2 / P3B: Both. P2: invent suitable details. P3B: follow Data File + task (who, points, tone). Letter and email share the same body logic; layout differs mainly in the opening block and closing.

PAT
PurposeWrite to one reader (or organisation) to request, complain, apply, thank, or explain.
AudienceNamed person, company, school office, or organisation — match the task.
ToneFormal, polite, clear. No slang. Email can be slightly shorter, still formal.
Structure

Opening

  • Letter: sender address (if asked) → date → recipient → greeting
  • Email: Subject line → greeting (Dear Mr/Ms X, / Dear Sir or Madam,)
  • State why you are writing
  • End with thesis (main purpose) — last sentence of the opening paragraph

Body

  • 2–4 paragraphs
  • First sentence of each = topic sentence (one main idea only)
  • Then reason + detail / example (after the topic sentence)
  • Cover all task points

Closing

  • Restate request briefly
  • Sign-off: Dear Sir or Madam → Yours faithfully; named person → Yours sincerely
  • End with full name (email: add role / contact if useful)
Skeleton

Slots: [thesis / angle] · [topic / point] · [detail / example] · [other]

Opening

[Letter layout / Subject: …]

Dear [Name / Sir or Madam],

I am writing to [purpose]. I would like to [thesis — main request / point].

Body

First, [main idea 1]. This is important because [reason]. For example, [detail].

Second, [main idea 2]. [Supporting fact].

Finally, [main idea 3 / what you want them to do].

Closing

I should be grateful if you would [request].

Yours faithfully, / Yours sincerely,

[Full name]
Useful phrases
  • I am writing to enquire about…
  • I am writing to complain about… / to apply for…
  • I refer to your letter / email of [date]…
  • Could you please let me know whether…
  • I would appreciate it if you could…
  • Please find attached… (email)
  • I look forward to your reply.
  • Thank you for your attention to this matter.
