Paper 3 - Exam Skills

HKDSE English Language · paper map, listening skills, integrated skills and exam habits

Paper Map

Weighting & time

  • Paper 3 Listening and Integrated Skills = 30% of the subject
  • About 2 hours

Part A (Compulsory) — Listening

  • Everyone sits Part A
  • Short tasks while listening (note-taking, MC, form-filling, short answers, matching, etc.)

Part B — choose B1 or B2 — Integrated Skills (Data File)

B1 (easier) B2 (more demanding)
Task Listening + Data File Listening + Data File
Demand More straightforward More cognitively demanding
Highest level Level 4 (A+B1) Full range, including Level 5 / 5**
  • Same skills at different difficulty; Level 5 usually needs B2
  • One extended writing task (email, report, article, letter…)
  • Data File: emails, notes, articles, charts, etc.

How you are marked (Part B writing)

  • Content — task fulfilled; use DF; relevant, developed
  • Language — accuracy, range, tone fit
  • Organisation — clear structure for the genre
  • Appropriacy — register / tone / format fit the task and reader

Timing

  • One sitting for A + B — leave a clear block for the Part B writing task
  • Finish Part A notes cleanly; in Part B, skim DF first, listen with purpose, then write — leftover minutes to check DF facts and tone
Listening Skills

Listening for gist

  • Catch the main idea / purpose of a talk or conversation
  • Ask: what is this about? why are they speaking?
  • Don’t chase every word on the first pass
Example

Cha chaan teng manager talks about a staff rota change → gist = new shift plan for Open Day, not milk-tea prices.

Listening for detail

  • Hunt names, numbers, times, places
  • Spell carefully when the task requires it
  • Check units and dates against the question
Example

MTR meet-up: exit B2, 2:15 p.m. → write exit and time exactly; don’t invent “near the station”.

Note-taking while listening

  • Use abbreviations; leave space between points
  • Don’t write every word — key nouns, numbers, names
  • Keep handwriting readable for later use (esp. Part B)
Example

Typhoon plan talk → “Sig 8 → school close / bus cancel / WhatsApp parents” — short notes, not full sentences.

Predicting & listening with purpose

  • Read questions / headings before the audio
  • Underline keywords; predict what you will hear
  • Listen for those answers — not a random transcript
Example

Heading “Open Day volunteers” → expect duties, times, meeting point before the clip starts.

Integrated Skills

Data File navigation

  • Skim headings, emails, tables; mark useful bits
  • Map who / what / dates before deep reading
  • Don’t invent facts not in the DF or recording
Example

SCMP clipping + principal’s email disagree on date → use only what the instruction + DF allow; don’t “fix” with outside knowledge.

Task fulfilment

  • Cover every required point from the instruction sheet
  • Role, reader, purpose — tick them off as you draft
  • Genre features (greeting, subject line, sign-off) when needed
Example

Email to principal about Lion Rock hike risk → all bullets + formal register; missing one bullet costs Content.

Selecting & synthesising

  • Combine DF + listening; discard irrelevant DF pages
  • Prefer facts that answer the task — not every page
  • Paraphrase where natural; copy names/dates carefully
Example

Three DF emails + one audio clip on MTR crowding → pick only points that fit a proposal email; ignore the unrelated sports club memo.

Tone & register for the written task

  • Match genre: formal email to principal vs note to classmates
  • Stay consistent; don’t mix WhatsApp chat with formal report tone
  • Appropriacy marks reward fit to reader and purpose
Example

Report to teacher on Open Day feedback → semi-formal, clear headings; not slangy classmate chat.

Exam Habits

B1 or B2

  • Decide with your teacher before exam day — not under panic in the room
  • Level 5 usually needs B2; B1 caps at Level 4 (A+B1)

Headphones / room

  • Check volume early; raise your hand if there is a problem

Before audio

  • Read instructions and questions; underline keywords

During audio

  • Listen first, then write; don’t panic-blank

DF first pass

  • Map the file (who / what / dates) before deep reading

Don’t invent

  • Only DF + recording — no outside “knowledge” that contradicts the file

Timing

  • Leave time to re-read the written task for missing bullets, tone, and copy errors from the DF

Spelling of names / places from DF

  • Copy carefully — careless spelling of a DF name costs marks
