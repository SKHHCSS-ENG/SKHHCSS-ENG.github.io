P2 / P3B · especially P3B

Report

Present facts clearly under headings. Focus line in the introduction — not a debate thesis.

P2 / P3B: Both (especially P3B). Organise Data File facts under headings; follow task word limits.

PAT
PurposePresent facts clearly; analyse a situation; often give recommendations.
AudienceSupervisor, principal, committee — busy readers who want clarity.
ToneFormal, objective, calm. Facts over emotion. Use headings.
Structure

Introduction

  • Title: Report on [topic]
  • Focus line: purpose + what it covers
  • Not a debate thesis

Findings

  • Under each heading
  • First sentence = topic sentence (main finding only)
  • Then support, Data File detail and short interpretation (after the topic sentence)

Recommendations

  • Practical steps linked to findings
  • Name / role if required
Skeleton

Slots: [thesis / angle] · [topic / point] · [detail / example] · [other]

Introduction

Report on [topic]
The purpose of this report is to [aim]. It covers [areas].

Findings

Findings
1. [Main finding 1]. [Supporting detail / interpretation].
2. [Main finding 2]. [Supporting detail / interpretation].
3. [Main finding 3]. [Supporting detail / interpretation].

Recommendations

Recommendations
1. [Action 1] — so that [benefit].
2. [Action 2] — in order to [benefit].
Overall, [short summary]. If these steps are taken, [expected result].
Prepared by: [Name]
Useful Phrases
  • The purpose of this report is to…
  • This report examines / outlines…
  • According to the information provided,…
  • It was found that…
  • A major concern is that…
  • In view of the above findings…
  • It is recommended that…
  • Immediate action should be taken to…
