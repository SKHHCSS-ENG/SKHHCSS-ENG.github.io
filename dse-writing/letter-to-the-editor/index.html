P2 / P3B

Letter to the editor

Give your view on a public issue. Formal, polite, clear.

P2 / P3B: Both. P2: invent suitable details. P3B: follow Data File + task (who, points, tone).

PAT
PurposeGive your view on a public issue; persuade readers; sometimes complain or praise.
AudienceNewspaper / magazine readers and the editor.
ToneFormal, polite, clear. Strong views OK — no slang or insults.
Structure

Opening

  • Greeting: Dear Editor, (or Dear Sir or Madam,)
  • Name the issue
  • End with thesis (main view) — last sentence of the opening paragraph

Body

  • 2–4 paragraphs
  • First sentence of each = topic sentence (one main idea only)
  • Then reason + example (after the topic sentence)

Closing

  • Restate request/view briefly
  • Sign-off rule: Dear Editor / Dear Sir or Madam → Yours faithfully; named person (e.g. Dear Mr Chan) → Yours sincerely
  • Then full name
Skeleton

Slots: [thesis / angle] · [topic / point] · [detail / example] · [other]

Opening

Dear Editor,
I am writing regarding [issue / recent article].
I believe that [thesis].

Body

First, [main idea 1]. This matters because [reason]. For example, [example].
Second, [main idea 2]. If [situation continues], [result].
Finally, I suggest that [action]. This would help [benefit].

Closing

I hope readers will support [request / view].
Yours faithfully,
[Full name]
Useful phrases
  • I am writing to express my concern about…
  • I refer to the recent discussion on…
  • It is widely believed that…; however,…
  • One major problem is that…
  • I firmly believe that…
  • The authorities should consider…
  • In the long run, this would…
  • I hope the editor will publish this letter so that…

中文 gloss（harder words）：persuade — 說服 · thesis — 中心論點 · topic sentence — 主題句 · concern — 關注／憂慮 · authorities — 當局 · faithfully — 忠實地（信末） · sincerely — 誠摯地（信末） · request — 請求
