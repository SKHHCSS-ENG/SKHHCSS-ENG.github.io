P2 · Part A

Questionnaire

Complete every prompt on the form. Short, relevant answers — not one long essay.

P2 / P3B: Common in P2 Part A (about 200 words in total). Answer every question on the form; invent details that fit the situation. A form may also appear in P3B — follow the Data File and the printed prompts.

PAT
PurposeComplete the given questionnaire — answer every prompt clearly, with details that fit the situation.
AudienceThe organisation or person who set the form (a school, institute, club, or company).
ToneClear, polite, and reasonably formal. Use “I” when you are writing as the person in the task. Not a letter unless the form asks for one.
Structure

Opening

  • Fill in any heading blanks (course name, date, class) if they are there
  • Do not add your own title, “Dear…”, or a long introduction unless the form asks for one
  • Start with the first printed prompt

Body

  • Answer every prompt in order — do not write one long essay that ignores the questions
  • For each answer: a direct point + a short reason or example
  • Share the word limit across all questions (Part A is often about 200 words in total)
  • Invent details that fit the situation and stay consistent
  • If a rare task asks you to write the questions yourself, keep items short, clear, and in a sensible order — otherwise, complete the form given

Closing

  • The last prompt is often a suggestion or overall comment — end there
  • No Yours faithfully unless the form asks for a name or signature
Skeleton

Slots: [heading blank] · [prompt / point] · [detail / example] · [other]

Opening

[Questionnaire heading already printed]
[Fill in any blank, e.g. course / event name]

Body

[Prompt 1, e.g. Why did you take part?]
I wanted to [aim] because [reason]. For example, [example].
[Prompt 2, e.g. What did you like best?]
The most useful part was [specific point]. It helped me [benefit].

Closing

[Prompt 3, e.g. What changes would you recommend?]
One change I would suggest is [suggestion]. This would [benefit].
Useful Phrases
  • I decided to take part because…
  • The most useful part was…
  • What I liked best was…
  • For example, during the session we…
  • One difficulty I faced was…
  • One change I would recommend is…
  • This would help students to…
  • Overall, I found the experience…
