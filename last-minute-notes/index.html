Paper 1 - Reading

Paper 1 - Exam Skills
  • Weighting — 20% · 1½ hrs → A + B together
  • A (10%) — compulsory
  • B (10%) — B1 (easier — A+B1 caps at Level 4) / B2 (full range, incl. 5 / 5**)
  • Choice — pick B1 / B2 with your teacher before exam day → leave time for B
  • Skim — title, subtitles, first/last paragraphs → then scan for the keyword
  • Main idea — whole paragraph, not one colourful detail
  • Infer — stay in the text
  • Watch — synonyms, word limits, “from paragraph X”
  • Gap-fill — meaning + word form
  • Open-ended — answer, then stop → check spelling and every required element

Paper 2 - Writing

Paper 2 - Exam Skills
  • Weighting — 25% · 2 hrs → A + B together
  • A (10%) — compulsory · ~200 words
  • B (15%) — choose 1 of 4 · ~400 words
  • Choice — topic + genre you can finish well → mark with an X in the answer book
  • Marks — Content / Language / Organisation
  • Before writing — purpose, audience, tone → tick off every task bullet
  • Plan — a few minutes · 3–4 points · one idea per paragraph
  • Language — clear beats rare words used wrongly
  • Timing (classroom guide, not HKEAA) — ~40 min A / ~70–75 min B → short check
  • Word guides — targets, not automatic deductions
  • Final check — 3–5 min → bullets, genre features, tone, slips

Paper 2 - Writing Formats
  • Follow — the task’s stated format (email / blog / questionnaire may also appear in A)
  • Letter to the Editor — public argument / complaint · thesis last in the opening · Yours faithfully / sincerely
  • Formal letter / email — one reader or organisation (request / complain / apply)
  • Article — hook + angle · no letter sign-off
  • Blog — conversational · no Dear… / Yours…
  • Review — overall judgement · strengths + weaknesses
  • Proposal — aims, details, resources, benefits → ask for approval
  • Report — facts under headings · findings → recommendations
  • Speech — write for the ear · greet, thesis, signposted points → thank the audience

Paper 3 - Listening & Integrated Skills

Paper 3 - Exam Skills

  • Weighting — 30% · about 2 hrs
  • A — compulsory listening
  • B — B1 / B2 · listening + Data File → one extended writing task
  • B1 — more straightforward (A+B1 caps at Level 4) / B2 — more demanding (full range, incl. 5 / 5**)
  • Choice — pick B1 / B2 with your teacher before exam day
  • Part B marks — Content / Language / Organisation / Appropriacy (register, tone, format)
  • Before audio — read questions → underline keywords
  • Listen — gist + detail (names, numbers, times)
  • Notes — short + readable
  • Part B order — skim the Data File first → listen with purpose → write
  • Sources — Data File + recording only · don’t invent facts → copy names / places carefully
  • Check — every required bullet → facts, tone, copy errors

Paper 4 - Speaking

Paper 4 - Exam Skills
  • Weighting — 10% (SBA is separate)
  • Order — Group Interaction (GI) → Individual Response (IR)
  • GI — usually 3–4 candidates · ~8 min for a group of 4
  • IR — ~1 min · one question from the examiner
  • Marks — pronunciation & delivery / communication strategies / vocabulary & language patterns / ideas & organisation
  • Open GI — restate the task → short turns · invite others · link + reason / example
  • Disagree — politely + alternative · clarify if you miss something → repair a slip and move on
  • IR structure — clear stance → two reasons / examples → short close · answer the examiner’s question, not a second GI
  • Keep going — paraphrase if stuck · don’t memorise a whole speech
  • Eyes — group in GI / examiner in IR
  • If you blank — repeat the question → one simple point first

Junior Grammar

Core forms for S1–S3:

  • Simple present — habits, facts, timetables · base / -s · do/does in negatives + questions (not don’t walks)
  • Verb to be — am / is / are · no do/does with be (Is she…? not Does she is…?)
  • Present continuous — happening now / a near-future plan · am/is/are + -ing
  • Present perfect — past with a link to now (just, already, yet, since, for) · have/has + past participle · not with a finished past time (yesterday) → use simple past
  • Simple past — finished past time · after did, base verb (Did she go?)
  • was / were — was with I/he/she/it · were with you/we/they
  • Past continuous — was/were + -ing · often I was walking when it started to rain
  • Will — decisions now / offers / predictions without strong evidence
  • Be going to — plans already decided / predictions with present evidence (dark clouds → It’s going to rain)
  • Passive (simple present / simple past) — action matters more than who did it · be + past participle (The hall is cleaned / was cleaned) · don’t add -ed twice
  • Reported speech — say + (that)… · tell + person + (that)… · tense shift when the reporting verb is past
  • Yes/no reported — if/whether + statement order (he asked if I was ready)
  • Zero conditional — If + present, present (facts)
  • First — If + present, will + base · don’t put will in both halves
  • Second — If + past, would + base · If I were you… is the usual polite form
  • Transitional words — however, therefore, for example, in addition

Stretch (on the full Junior Grammar page) — perfect continuous · future continuous + perfect · past perfect · full passive table · reported Wh-questions · conditionals Type 3 + mixed · comparative / superlative adverbs
